# apis/ — Эталонные OpenAPI

> Статус: **РЕФЕРЕНС** (опциональный). Команды могут опираться на эти спецификации или писать свои.

Эта директория предназначена для размещения эталонных OpenAPI-спецификаций сервисов NeoMarket.

## Кто наполняет

Каждая команда описывает OpenAPI своего сервиса в репозитории [neomarket-protocols](../../../neomarket-protocols/). Лучшие спецификации могут быть включены сюда как эталонные.

Как внести вклад и получить бонус — читай в README репозитория neomarket-protocols.

## Чего здесь нет (и почему)

В этом семестре apis/ остаётся пустым намеренно: команды сами формируют стандарт через реальную разработку. Это не упущение — это учебная задача.
